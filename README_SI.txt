CALme - ආරම්භක PWA ව්‍යාපෘතිය

ඇතුළත් දේ:
- Basic calculator (+, -, ×, ÷, %, +/-)
- Light / Dark mode
- Sinhala / English interface
- Calculation history with automatic date and time
- History saved locally in the browser on this device
- Export / Restore JSON backup
- Optional button sound
- Offline cache (after first successful load)

දුරකථනයෙන් පරීක්ෂා කිරීම:
1. ZIP ගොනුව Extract කරන්න.
2. index.html ගොනුව browser එකකින් විවෘත කරන්න.
3. වඩා හොඳ offline/PWA පරීක්ෂාව සඳහා HTTPS hosting එකකට upload කර browser menu එකෙන් Install app / Add to Home screen තෝරන්න.

වැදගත්:
- මෙය ක්‍රියාකාරී web/PWA prototype එකකි; තවම Android APK/AAB ගොනුවක් නොවේ.
- දත්ත browser local storage තුළ පවතී. Browser data clear කළහොත් මැකිය හැකි නිසා නිතර Backup ගන්න.
- AdMob දැන්වීම් තවම සම්බන්ධ කර නැත. සැබෑ දැන්වීම් සඳහා Android build එකක් සහ AdMob account/ad unit IDs අවශ්‍ය වේ.
- Google Play නිකුතුවට Android wrapper/build, app signing, privacy policy, store listing සහ Play Console පරීක්ෂණ අවශ්‍ය වේ.
